# vladkorolkov-music

Personal music website, styled after [yegor256.com](https://www.yegor256.com/) (GitHub Pages + Jekyll).

Content is currently Lorem Ipsum.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Site will be at `http://localhost:4000`.

## Deployment

Push to `main`. GitHub Pages builds it automatically (enable in Settings → Pages → Deploy from branch `main`).
